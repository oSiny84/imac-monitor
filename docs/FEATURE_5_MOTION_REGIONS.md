# 기능 5 — 감지 영역과 제외 영역

2026-10-20 구현. 카메라 영상에서 움직임을 판단할 영역을 정하고, 창문·시계·모니터처럼 반복 움직임이 있는 부분을 제외할 수 있습니다. **영상 가림/개인정보 마스킹 기능은 아닙니다.** 실시간·원본 녹화·썸네일에는 제외한 영역도 그대로 나옵니다.

## 설정

1. iMac에서 감시를 시작한 뒤 설정 → `감지·제외 영역`의 `영역 편집…`을 엽니다.
2. `감지 영역 추가 (초록)` 또는 `제외 영역 추가 (빨강)`을 선택하고 화면에서 사각형을 드래그합니다. 서로 겹쳐도 되며 **제외 영역이 우선**합니다.
3. `마지막 변경 취소`로 잘못 그린 영역을 되돌리거나 `전체 화면으로 초기화`로 모두 지웁니다. 개별 사각형의 이동/크기 조절 대신 취소 후 다시 그리는 첫 버전입니다.
4. `영역 적용` → 바깥 설정 창의 `저장`을 누른 뒤 **감시 중지·다시 시작**해야 실제 분석에 반영됩니다. 편집창의 `취소`는 편집을 반영하지 않습니다.

미리보기는 이미 감시 중인 캡처 세션을 재사용하며 새 카메라 세션·권한 요청·감시 시작을 수행하지 않습니다. 감시 중지 상태에서 편집기를 열면 검은 배경에서 영역만 편집할 수 있습니다. 이후 감시를 시작했다면 편집기를 닫고 다시 열어 미리보기를 연결하세요. 설정에서 다른 카메라를 선택했어도 재시작 전에는 기존 촬영 카메라의 화면입니다.

미리보기와 분석 좌표는 좌우 반전하지 않은 카메라 영상의 좌상단 기준입니다. 편집창은 로컬 사용자의 설정 조작으로만 열며, 원격 접속이 이 창을 띄우거나 디스플레이를 켜지는 않습니다. 실제 iMac에서 영상의 좌우·상하와 그린 사각형이 일치하는지 확인해야 합니다.

## 규칙과 저장

- 초록 사각형이 없으면 전체 화면에서 검사합니다. 하나라도 있으면 그 합집합만 검사합니다. 그중 빨간 사각형의 합집합을 뺍니다.
- 감지·제외 각각 최대 12개, 사각형 너비·높이는 화면의 2% 이상입니다. 화면 밖·비정상 숫자·유효 감지 표본이 하나도 없는 설정은 저장하지 않습니다.
- 좌표는 0~1 정규화 값으로 `config.json`의 `motionRegions.detection`/`exclusion`에 저장합니다. 이전 설정에 이 필드가 없으면 전체 화면 감지를 유지합니다.
- 저해상도 luma 표본 중 유효 영역의 표본만 배경 비교·밝기 보정·변화 비율 계산에 사용합니다. 제외 영역의 변화가 변화 비율이나 밝기 보정을 통해 감지를 일으키지 않도록 분리했습니다.
- 영역별 별도 민감도는 아닙니다. 기존 픽셀 차이 임계값·변화 픽셀 비율을 유효 영역 전체에 적용합니다. 너무 좁은 영역이나 유효 영역 전체의 균일한 밝기 변화는 기존 밝기 보정의 영향을 받으므로 실제 움직임으로 민감도를 조정하세요.
- 원본 해상도·녹화 전후 보존·보관 및 보호 정책·카메라 프레임 정지 감지는 바꾸지 않습니다. 영역 밖에서 움직임이 있어도 실제 프레임 콜백은 계속 수신되므로 카메라 장애로 보지 않습니다.

## 검사와 Mac 인수 테스트

Swift 테스트를 4개 추가했습니다: 전체 화면 기본값/여러 감지 영역/제외 우선, 잘못된 사각형·전체 제외·개수 제한, 새 설정 왕복과 이전 설정 호환, 실제 픽셀 버퍼의 제외/영역 밖 변화 무시와 유효 영역 감지. **Windows에는 Swift/macOS 프레임워크가 없어 실행하지 못했습니다.** AppKit 편집창·미리보기와 실제 카메라도 아직 미검증입니다.

1. 최신 ZIP의 빌드 파일을 실행해 새 `MotionRegionsTests`와 `MotionDetectorTests`가 통과하는지 확인합니다.
2. 감시 중 편집기를 열어 좌우·상하 방향을 확인하고 문 같은 감지 영역과 창문 같은 제외 영역을 그립니다. 적용·저장·재시작 뒤 재실행해도 설정이 유지되어야 합니다.
3. 조용히 두어 초기 배경을 잡은 뒤 제외/영역 밖에서만 움직이고 새 사건이 생기지 않는지 확인합니다. 다음에는 유효 영역 안에서 움직여 사건이 생기는지 비교합니다. 다른 사물이나 조명 변화가 동시에 들어오지 않도록 합니다.
4. 전후 보존과 사건 병합 지연을 고려해 마지막 움직임 후 `후 보존 + 전 보존 + 약 15초` 이상 기다려 결과를 비교합니다. 예전 사건 파일이나 아직 병합 중인 조각을 새 감지 결과로 혼동하지 않습니다.
5. 전부 제외하는 설정은 거부되는지, 초기화하면 다시 전체 화면에서 감지하는지, 편집 취소가 저장하지 않는지 확인합니다.
6. 감시 중지 상태에서 편집기를 열어도 카메라가 켜지지 않아야 하며, 닫은 뒤 기존 감시·녹화가 중단되지 않아야 합니다. 화면 꺼짐/잠금 인수 테스트는 기존 절차로 다시 확인합니다.

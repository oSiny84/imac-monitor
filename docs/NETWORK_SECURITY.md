# 네트워크 및 인증 경계

## 외부에 노출되는 표면

- HTTPS 게이트웨이 TCP 8443
- WebRTC ICE UDP/TCP 8189

MediaMTX의 RTSP 8554와 WebRTC HTTP 8889는 `127.0.0.1`에만 bind합니다. API, metrics, pprof, playback, RTMP, HLS, SRT, MoQ는 비활성화합니다. ICE listener는 미디어 연결에 필요해 외부 인터페이스에서 대기하지만, 세션별 ICE 자격 증명은 인증된 HTTPS 협상 응답을 통해서만 전달됩니다.

WebRTC 미디어는 별도 TURN·릴레이 서버를 거치지 않고 휴대폰과 iMac 사이에서 직접 연결합니다. 따라서 공유기의 UDP 8189 포트포워딩을 기본으로 사용하고, UDP가 차단된 환경을 위해 TCP 8189 직접 연결만 보조로 엽니다.

## 인증

- 비밀번호: 무작위 16바이트 salt, PBKDF2-HMAC-SHA256 600,000회, 32바이트 결과.
- 저장: 원문 비밀번호를 저장하지 않으며 `gateway.json`은 0600 권한으로 생성.
- 세션 토큰: 암호학적 난수 32바이트. 서버 메모리에는 SHA-256 해시만 보관.
- 쿠키: `Secure`, `HttpOnly`, `SameSite=Strict`, `__Host-` 접두어.
- 만료: 기본 유휴 30분, 절대 24시간. 앱/게이트웨이 재시작 시 모든 세션 무효화.

HTTPS 게이트웨이는 인증된 앱 세션에 속하며 촬영 중지·화면 전용 예약 휴식에서는 계속 실행됩니다. 녹화 접근에는 같은 웹 인증이 필요합니다. 감시 중지 자체는 웹 로그아웃이나 접속 차단이 아니며, 전체 원격 접속을 중지하려면 앱을 종료합니다. 시스템 잠자기 시 게이트웨이를 중지하고 깨어나면 재시작하므로 웹 재로그인이 필요할 수 있습니다.
- 로그인 제한: IP별 1분 창, 5회 실패부터 지수형 차단.
- 상태 변경: 정확한 HTTPS Origin 확인. 로그아웃은 별도 CSRF 토큰도 요구.

게이트웨이는 `X-Forwarded-For`를 신뢰하지 않습니다. 공유기에서 직접 전달되는 연결의 실제 원격 주소를 로그인 제한 키로 사용합니다.

## 미디어와 녹화

- 브라우저와 게이트웨이: HTTPS.
- WebRTC 미디어: DTLS/SRTP.
- 카메라 게시: 동일 Mac의 loopback RTSP/TCP.
- 녹화: 인증 쿠키가 있어야 목록 및 파일 접근 가능. `http.ServeContent` 기반 Range 요청만 허용.
- 파일 식별자는 제한된 `.mp4` basename만 허용하며 경로 이탈과 symlink를 거절.
- 앱 데이터의 루트·녹화·스풀·진단·런타임 디렉터리는 시작할 때마다 소유자 전용 `0700`으로 맞추고, 설정 파일은 `0600`으로 저장.

## 운영상 남은 책임

- 신뢰 가능한 CA 인증서의 발급과 갱신.
- DDNS 계정과 공유기 관리자 계정 보호.
- macOS 사용자 계정 및 디스크 암호화.
- 포트가 필요 없을 때 사용자가 포트포워딩을 닫는 운영.

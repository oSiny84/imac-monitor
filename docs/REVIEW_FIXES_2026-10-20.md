# 기능 5·6 후속 리뷰 수정 — 2026-10-20

사용자가 리뷰에서 지적된 문제를 모두 수정하도록 요청해 아래 네 결함을 수정했습니다. 소스 수정과 Windows에서 실행 가능한 회귀 검사까지의 기록이며, Mac에서 정상 동작을 확인했다는 뜻은 아닙니다.

## 수정 사항

1. 감지 영역 검증과 실제 픽셀 분석이 서로 다른 좌표를 사용하던 문제: 공통 표본 마스크를 사용합니다. 720p에서 감지 x=0~0.02, 제외 x=0.008~0.028 설정은 이제 실제와 동일하게 표본 0개로 계산하고 저장을 거부합니다.
2. 2%×2% 등 극소 영역의 표본 한 개가 밝기 보정으로 상쇄되던 문제: 최소 16개 및 가로·세로 각각 두 위치를 요구합니다. 실제 프레임 크기로도 검사하며, 부족하면 정상 무동작으로 처리하지 않고 감시 오류를 알립니다. 유효한 작은 영역의 국소 움직임 감지와 균일 조명 변화 억제는 유지합니다.
3. 페이지 캐시에 들어간 실시간 플레이어가 영구 종료되어 뒤로가기 후 검은 화면으로 남던 문제: 캐시 저장은 일시 중단, 복원은 로그인 재확인 후 재연결합니다. 일반 종료·인증 만료는 계속 영구 종료합니다. 중복 복원 이벤트와 오래된 인증/SDP 응답이 새 연결을 덮거나 닫지 않도록 막았습니다.
4. FFmpeg 경로의 `$`가 MediaMTX에서 환경변수로 해석되던 문제: 실제 경로를 프로세스 환경변수 값으로 전달하고 고정 토큰만 한 번 확장합니다. 공백·따옴표·리터럴 `$`·한글을 포함하는 값을 다시 분리하거나 확장하지 않습니다. CR/LF/NUL은 거부합니다.

로컬 녹화 인코딩·전후 보존·보호 정책과 TURN 없는 직접 연결 방식을 바꾸지 않았습니다. 기존에 너무 작게 저장된 영역은 새 검증에서 거부되므로 설정을 넓히거나 전체 화면으로 초기화해야 합니다. 설정 창에 한해서 영역 검증을 보류해 기존 영역과 다른 값을 보존한 채 수정할 수 있게 했습니다. 실제 저장·감시 시작은 전체 검증을 통과해야 하며, 이전 전원 예약도 그대로 비교하므로 잘못 기본값으로 대체하지 않습니다.

## 실행한 검사

- Node 웹/실시간 수신기 회귀 검사 35개 전부 통과. BFCache 생명주기, 표시 이벤트 순서, 복원 전 인증 만료, 늦은 인증/SDP 응답, 재시도 상한 유지 등을 포함합니다. 실제 브라우저/영상 전송 대신 대역 객체를 사용합니다.
- Go 검사 29개 중 26개 통과, Windows 심볼릭 링크 권한 및 macOS/Linux FFmpeg 파일 디스크립터 제약으로 기존 3개 건너뜀. `go vet ./...`와 Mac Intel 게이트웨이 교차 빌드도 통과했습니다.
- 빌드 스크립트 회귀 검사 8개 통과. 실패 시 기존 설정/바이너리 보존, 인코더 출력 및 체크섬 처리 등을 재확인했습니다.
- Node 검사는 뉴욕 시간대로도 35개 통과했고 JavaScript 구문·변경 내용 형식 검사도 통과했습니다.
- Swift 회귀 테스트를 추가했습니다. 실제 픽셀 버퍼로 경계·극소·유효 마스크 및 해상도 변경, 이전 설정의 편집 복구를 확인하고, 프로필 경로의 환경변수 전달과 고정 MediaMTX 설정도 검사하도록 구성했습니다. 특수문자 폴더의 대역 실행 파일을 실제 MediaMTX가 호출하는 포트 비활성화 통합 검사도 추가했습니다. **Swift/macOS가 없어 실행하지 못했습니다.**

## Mac에서 남은 확인

최신 ZIP을 새 폴더에 풀고 `Build MacMonitor.command`를 실행합니다. 자동 Swift 테스트가 실패하면 빌드를 중단하고 로그를 보존하세요.

- 감지/제외 사각형의 미리보기 좌표와 실제 감지가 일치하는지 확인합니다. 너무 작거나 한 줄만 남은 영역은 거부되고, 충분한 표본을 가진 작은 영역에서는 움직임이 감지되어야 합니다.
- Safari에서 다른 페이지로 이동한 뒤 뒤로/앞으로가기로 돌아와 로그인 확인 후 실시간 영상이 복원되는지 확인합니다. 캐시 사용 여부와 브라우저/OS 버전을 기록합니다. 그 사이 로그아웃한 경우 영상이 다시 나오면 안 됩니다.
- 특수문자 경로 네이티브 회귀 테스트와 원본·표준·절약 실제 송출을 확인합니다. 설정 유효성 검사만으로 실제 VideoToolbox 실행 성공을 보장하지 않습니다.
- 기존 카메라·녹화·잠금/화면 꺼짐·예약 잠자기·외부 회선 인수 항목은 [전체 절차](MAC_VALIDATION.md)대로 확인합니다.

최신 소스/ZIP의 GitHub 게시에는 Git 인증 갱신이 남아 있습니다. 로컬 ZIP과 원격 저장소가 같다고 가정하지 마세요.

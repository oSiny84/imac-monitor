# 2026-10-20 재점검

이 문서는 Mac 실기 테스트 전에 다시 확인한 오류와 검증 범위를 기록합니다. 검증 환경은 Windows이며 Swift 컴파일·카메라·VideoToolbox·예약 전원은 아직 대상 Mac에서 확인해야 합니다.

## 수정한 문제

- MediaMTX 다운로드: 공식 `sha256sum -b` 체크섬의 `*파일명`을 인식하지 못해 정상 다운로드도 실패하던 파서를 수정했습니다. 텍스트·바이너리 형식을 모두 처리하고, 불일치 시 기존 설치를 보존하는 회귀 검사를 추가했습니다.
- 더블클릭 빌드: Go 공식 설치 경로 `/usr/local/go/bin`을 실행 파일·빌드·진단 스크립트 PATH에 추가했습니다. 설치 직후 Finder 세션에서도 Go를 찾습니다.
- 모바일 첫 화면: `/`를 `/index.html`로 바꾸면서 파일 서버가 다시 `./`로 보내던 무한 리디렉션을 제거했습니다. 첫 화면은 HTML 200을 반환하고 알 수 없는 주소는 404를 반환합니다.
- 녹화 시간: 파일 이름은 Mac의 현지 시각인데 UTC로 해석하던 부분을 수정했습니다. 한국 시간 파일이 웹 목록에서 9시간 뒤로 표시되지 않도록 했습니다.
- 로그인 만료: 인증이 만료되면 로그인 화면으로 돌아가고 녹화 플레이어를 정리합니다. 녹화 목록을 다시 읽을 때 과거 오류 문구도 지웁니다.
- 감시 시작·중지: 이전 시작 작업의 늦은 콜백이 새 세션을 종료하지 않게 했습니다. 중지 요청이 겹치면 하나의 정리 작업을 공유하고 끝난 뒤 완료 콜백을 보냅니다.
- 카메라: 인코더에 맞는 1280×720을 지원하지 않는 장치는 명시적으로 오류를 표시하고, 캡처 세션이 실제 시작했는지 확인합니다.
- 사건 녹화: 가까운 움직임이 같은 5초 세그먼트를 필요로 하면 하나의 사건으로 합쳐 앞 사건의 병합이 뒤 사건의 사전 영상을 소비하지 않도록 했습니다.
- 로그 쓰기: 디스크 I/O 오류가 발생했을 때 진단 로그의 구형 쓰기 API로 앱이 종료되지 않도록 throwing API를 사용합니다.
- 인코더 장애: 입력 파이프에 `F_SETNOSIGPIPE`를 적용해 자식 프로세스 종료 시 앱이 SIGPIPE로 죽는 대신 쓰기 오류를 통한 복구를 수행하게 합니다. 로컬 RTSP 출력도 실패를 무시하지 않고 기존 복구 경로로 전달합니다.
- 예약 깨우기: 낮에 수동 중지한 감시가 관계없는 깨우기마다 재개되지 않게 했습니다. 잠든 사이 예약 재개 시각을 통과한 경우에는 재개합니다. 화면 끄기 작업이 지연되더라도 대기 중 발생한 사용자 입력을 우선합니다.

## 실행한 검사

- Go 게이트웨이 테스트 11개 통과: 첫 화면·정적 파일, 비로그인 접근 거부, 녹화 목록·구간 재생, 로그아웃 CSRF·세션 폐기, 현지 시각 등.
- `go vet ./...` 통과, `CGO_ENABLED=0 GOOS=darwin GOARCH=amd64` 게이트웨이 교차 빌드 성공.
- 브라우저 JavaScript `node --check` 통과.
- 셸 회귀 검사 8개 통과. 모든 `.sh` 및 `.command`의 `bash -n` 통과.
- Apple 리소스 plist 3개 파싱 통과, Git diff 공백 오류 검사 통과.
- 배포 ZIP 생성 시 전체 파일 SHA256, CRC, 셸 LF 줄바꿈, Unix 실행 권한을 검사합니다.

새 Swift 회귀 테스트는 오래된 콜백·중복 중지·공유 세그먼트·예약 시각 통과·깨진 인코더 파이프를 대상으로 추가했습니다. Windows에는 Swift 및 macOS 프레임워크가 없으므로 Swift 테스트 통과로 간주하지 않습니다. Mac의 `Build MacMonitor.command`가 일반 Swift 테스트와 Thread Sanitizer를 실행합니다.

## Mac에서 우선 확인할 것

최신 ZIP을 새 폴더에 압축 해제하고 개발 도구를 준비한 뒤 `Build MacMonitor.command`를 실행합니다. 자세한 절차는 루트의 `MAC_TEST_START_HERE.txt`를 따릅니다.

1. 빌드·진단 완료 후 카메라 권한, 첫 영상 및 사건 MP4 생성을 확인합니다.
2. 감시 중지→시작을 반복해 카메라·인코더가 정상 재개되는지 확인합니다.
3. 화면 꺼짐·잠금 각각 2분 동안 하트비트와 움직임 녹화가 이어지는지 확인합니다.
4. 외부 접속 준비 후 모바일 첫 화면·로그인·실시간 영상·녹화 재생과 표시 시각을 확인합니다.
5. 예약 두 모드와 수동 중지 후 낮 시간 수동 잠자기·깨우기를 확인합니다.

오류가 나면 `dist/build-*.log`, 오류 화면, 해당 시각의 진단 로그를 보존하세요. 최신 소스 ZIP은 `releases/`에 있으며 완성된 Mac 앱 설치 파일은 아닙니다.

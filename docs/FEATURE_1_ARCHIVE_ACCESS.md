# 기능 1 — 감시 중지 중에도 원격 녹화 보기

2026-10-20 구현. 카메라·인코더·실시간 영상 서버와 HTTPS 게이트웨이의 실행 수명을 분리했습니다. 기능 2~6은 이번 변경에 포함하지 않습니다.

## 동작

- 앱 비밀번호 확인 뒤 HTTPS 설정이 있으면 웹 서버를 시작합니다. 카메라 권한과 감시 시작은 녹화 목록·재생의 조건이 아닙니다.
- `감시 중지`, 촬영 장애·복구, 화면만 끄기 휴식에서는 웹 서버와 기존 웹 로그인 세션을 유지합니다. 웹 인증 및 만료 정책은 동일합니다.
- 웹 서버가 실패하면 감시를 재시작하지 않고 독립적으로 약 10초 주기로 재시도합니다. 웹 오류는 메뉴 막대의 원격 녹화 상태에 표시합니다.
- `gateway.json`을 처음 만들거나 변경하면 약 10초 주기로 감지합니다. 변경이 없으면 서버를 재시작하지 않습니다. 설정 삭제는 웹 서버를 중지합니다. 인증서 내용만 같은 경로에 교체했다면 메뉴의 `원격 웹 다시 시작`으로 반영합니다.
- 앱 종료 때는 감시와 웹 서버 정리를 모두 기다립니다. 시스템 잠자기 때는 웹 서버를 중지하고 깨어나면 감시 상태와 관계없이 다시 시작합니다.
- 웹 서버는 시스템 잠자기 방지 assertion을 추가하지 않습니다. Mac 전체가 잠자기이거나 전원이 꺼지면 접속할 수 없습니다. 수동 감시 중지 후 일반 유휴 잠자기도 여전히 가능합니다. 화면 전용 예약의 기존 잠자기 방지는 유지됩니다.
- 실시간 서버를 사용할 수 없으면 모바일에 안내를 띄우고 녹화 탭을 엽니다. 약 10초마다 확인하며 감시가 재개되어도 사용자가 재생 중인 녹화 화면을 강제로 바꾸지 않습니다. 실시간 탭을 선택하면 영상을 다시 연결합니다.

## 검사

- Go 테스트 13개 통과. 새 검사에서 같은 로그인 세션으로 실시간 서버 실행 중·중지 후 각각 상태 조회, 녹화 목록, MP4 Range 재생을 확인하고, 휴식 중 비로그인 접근도 거부되는지 확인했습니다. HTTP 503을 정상 실시간 서버로 표시하지 않는 검사도 추가했습니다.
- `go vet ./...`, Darwin/amd64 게이트웨이 교차 빌드 통과.
- Node 브라우저 제어 테스트 4개 통과: 감시 없는 로그인 시 녹화 열기·재생, 감시 중지/재개 시 화면 전환, 녹화 재생 중 불필요한 실시간 연결 방지, 로그아웃 이후 늦게 온 응답 무시. DOM 대역을 사용하는 기능 테스트이며 Safari의 실제 영상 렌더링 검증은 아닙니다.
- Swift 회귀 테스트 5개 추가: 변경 없는 시작·갱신의 중복 실행 방지, 감시 없이 최초 설정/변경/삭제, 독립 장애 복구와 오래된 콜백 무시, 종료/잠자기 후 재시도 중지와 깨우기 재개, 초기 시작 실패의 주기적 재시도.

Windows 환경에서는 Swift/macOS 프레임워크를 컴파일하거나 실행하지 못했으므로 Swift 테스트는 Mac 검증 대기입니다. Mac 빌드 스크립트가 새 XCTest를 포함해 일반·Thread Sanitizer 검사를 실행합니다. `node --test scripts/test-web-archive.js`는 Node가 준비된 개발 환경에서 별도로 실행할 수 있습니다.

## Mac 인수 테스트

1. HTTPS 및 포트포워딩을 설정하고 앱 비밀번호를 입력합니다. 감시를 켜지 않고 메뉴에서 `원격 녹화 — 웹 서버 실행 중`을 확인한 뒤 휴대폰으로 로그인합니다.
2. 기존 녹화를 재생합니다. 없으면 먼저 감시를 시작해 사건 녹화를 만들고 감시를 중지합니다. 로그인·목록·탐색 재생이 계속 동작해야 합니다.
3. 감시 시작→중지를 반복합니다. 녹화 재생과 웹 세션이 유지되어야 하며 실시간 탭은 사용할 수 없을 때 녹화 안내를 보여야 합니다.
4. 화면만 끄기 예약을 짧게 설정합니다. 휴식 중에는 카메라·인코더가 멈추지만 원격 목록·재생은 계속되어야 합니다. 재개 후 실시간 탭에서 다시 연결합니다.
5. 앱 종료 시 HTTPS 포트도 닫히는지 확인합니다. 앱 재실행은 앱 비밀번호 확인 후 웹 서버를 시작해야 합니다.
6. 시스템 잠자기에서는 접속 불가, 깨운 뒤 감시를 켜지 않아도 웹 서버가 재개되는지 확인합니다. 서버가 재시작되므로 웹 재로그인은 정상입니다.
7. 촬영 중 메뉴의 `원격 웹 다시 시작`을 눌러 웹 세션은 새로 로그인해야 하지만 촬영·녹화는 계속되는지 확인합니다. 기존 시스템 예약이 있었다면 테스트 종료 후 복원합니다.

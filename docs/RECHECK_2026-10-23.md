# 2026-10-23 빌드 도구 확인 수정

대상 iMac의 첫 원클릭 빌드에서 Go 설치 후 `xcodebuild`가 `tool 'xcodebuild' requires Xcode` 오류로 멈춘 보고를 바탕으로 수정했습니다.

## 수정한 문제

- Xcode 선택: Command Line Tools만 선택된 상태에서는 `/usr/bin/xcodebuild`가 존재해 명령 확인을 통과한 뒤 xcode-select 오류로 끝났습니다. `build-app.sh`가 버전 확인 전에 `xcode-select -p`가 `.app/Contents/Developer`인지 검사하고, 아니면 Xcode 14.2 설치와 `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer` 실행을 안내합니다.
- Swift 버전: Xcode 14의 `swift --version` 첫 줄은 `swift-driver version: 1.62.15 Apple Swift version 5.7.2 (...)`입니다. 네 번째 칸을 읽던 파서가 `Apple`을 버전으로 읽어 Xcode 14.2를 선택해도 `Swift 5.7.x is required; found Apple`로 실패했을 것입니다. `build-app.sh`와 `diagnose.sh` 모두 `Swift version` 다음 값을 읽도록 고쳤습니다.
- 문서: `SETUP_MAC.md`와 `MAC_TEST_START_HERE.txt`에 Xcode 14.2 다운로드 위치와 선택 명령을 추가했습니다.

## 실행한 검사

- `scripts/test-script-regressions.sh`: 두 스크립트의 실제 Swift 버전 파이프라인을 Xcode 14.2 출력으로 실행하는 검사를 추가했습니다. 이전 스크립트에서는 실패하고 수정본에서는 통과합니다.
- `bash -n scripts/build-app.sh scripts/diagnose.sh`

실제 Xcode 14.2 선택과 Swift 빌드는 대상 Mac에서 아직 확인해야 합니다.

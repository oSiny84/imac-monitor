# 2026-10-23 빌드 도구 확인 수정

대상 iMac의 첫 원클릭 빌드 보고를 바탕으로 수정했습니다. Go 설치 후 `xcodebuild`가 `tool 'xcodebuild' requires Xcode` 오류로 멈췄고, Xcode 14.2 선택 후에는 FFmpeg 확인에서 멈췄습니다.

## 수정한 문제

- Xcode 선택: Command Line Tools만 선택된 상태에서는 `/usr/bin/xcodebuild`가 존재해 명령 확인을 통과한 뒤 xcode-select 오류로 끝났습니다. `build-app.sh`가 버전 확인 전에 `xcode-select -p`가 `.app/Contents/Developer`인지 검사하고, 아니면 Xcode 14.2 설치와 `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer` 실행을 안내합니다.
- Swift 버전 출력: Xcode 14의 swift-driver는 `swift-driver version: 1.62.15 `를 줄바꿈 없이 stderr로, `Apple Swift version 5.7.2 (...)`를 stdout으로 씁니다. 기존 파서는 stdout만 읽어 버전 확인은 통과했지만 stderr 조각이 다음 오류 메시지 앞에 붙어 출력됐습니다(대상 iMac 로그에서 확인). `build-app.sh`와 `diagnose.sh`는 두 출력을 함께 읽고 `Swift version` 다음 값을 사용하므로 출력 형식과 관계없이 같은 버전을 얻고 조각을 남기지 않습니다.
- FFmpeg: Homebrew가 Monterey를 Tier 3로 낮춰 bottle이 거의 없으므로 `SETUP_MAC.md`와 `MAC_TEST_START_HERE.txt`에 Intel용 정적 FFmpeg를 `/usr/local/bin`에 설치하는 절차를 추가했습니다. 빌드 오류 메시지도 이 문서를 가리킵니다.
- 문서: Xcode 14.2 다운로드 위치와 선택 명령을 추가했습니다.

## 실행한 검사

- `scripts/test-script-regressions.sh`: 두 스크립트의 실제 Swift 버전 파이프라인을 Xcode 14.2 출력(stderr 분리형과 한 줄형)으로 실행해 버전이 5.7.2이고 다른 출력이 남지 않는지 확인합니다. 이전 스크립트는 stderr 조각이 남아 실패하고 수정본은 통과합니다.
- `bash -n scripts/build-app.sh scripts/diagnose.sh`

FFmpeg 설치 후의 Swift·Go 테스트와 앱 조립은 대상 Mac에서 아직 확인해야 합니다.
